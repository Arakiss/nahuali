## 0.3.0-beta.0 (2026-06-02)

- Opt-in tamper-evident hash-chained ledger in `nahuali-core`.
- Trust verdict surfaced by default in plain language in the CLI.
- Grouped `--help`, documented flags, examples, and shell completions.
- License moved from MIT to the Functional Source License (**FSL-1.1-MIT**).
  The code stays source-available — free to read, audit, use, modify, and
  self-host — and the only restriction is offering a competing commercial
  product or service. Each release becomes MIT two years after it ships; the
  earlier MIT-licensed beta remains MIT.
- Optional local `model2vec` embedder behind the `local-embeddings` build
  feature for real semantic recall, fully local and deterministic. The default
  build keeps the deterministic embedder; the semantic index schema version is
  now 3 — run `semantic-rebuild` after switching embedders.

## 0.2.0-beta.0 (2026-06-01)

- Result-level trust attached to authority recall.
- Conventional Commit subject enforcement on pull requests, with an opt-in
  local `commit-msg` hook.

## 0.1.0-beta.0 (2026-06-01)

Initial public beta seed for the local Rust memory engine: `nahuali-core`,
the `nahuali` CLI, `nahuali-mcp`, `nahuali-api`, the SurrealDB `memory_record`
ledger with rebuildable graph projection and Qdrant semantic index,
evidence-backed recall with authority context, knowledge-health inspection,
non-mutating operator reports, and the regression fixtures plus
release-candidate validation scripts.

Boundaries that still hold: no hosted accounts, tenants, billing, sync,
dashboards, or managed uptime; no stable 1.0 API guarantee; and no claim that
remembered information is true — Nahuali reports evidence, conflicts,
staleness, and health signals so callers can decide what to trust.
